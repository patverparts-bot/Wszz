# ZZWS: опубликованный сайт

- `index.html` — каталог и личный кабинет.
- `admin/` — интерфейс управления; действия требуют серверных прав.
- `help/user-guide.html` — инструкция покупателя.
- `help/admin-guide.html` — инструкция администратора.
- `js/context-help.js` — привязки значков помощи к соответствующим разделам.
- `js/api-client.js` — обращение к общему серверному API.
- `js/server-orders.js` — отправка и просмотр серверных заказов.
- `js/order-submit.js` — Excel-экспорт и форматирование; отдельных кнопок email/Viber в форме заказа нет.
- `apk-release.json` — данные прежнего публичного APK; резервный источник до первого выпуска через админку.
- `admin/apk-upload.js` — форма публикации новой версии владельцем; файл сохраняется сервером в закрытом хранилище.
- `docs/APK-RELEASES.md` — порядок публикации APK и данных выпуска.

GitHub Pages содержит статические файлы. База, серверный API, секреты и резервные копии размещаются отдельно и не должны публиковаться здесь. Скачивание Excel не создаёт заказ; для этого используется кнопка отправки. Файлы APK на GitHub Pages публичны.
