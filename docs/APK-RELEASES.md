# Публикация нового Android APK

Кабинет каталога и админка читают `apk-release.json` из корня сайта при открытии
и ещё раз перед скачиванием. Версия, описание, имя файла, размер и SHA-256
больше не заданы в JavaScript. Доступ к кнопке определяется серверным
разрешением Android аккаунта. Поля описания выводятся обычным текстом.

Для нового выпуска подготовьте подписанный production APK с новым именем,
например `ZZWS-7.0.9-production.apk`. Создайте текстовый файл UTF-8 с описанием
изменений, например `release-notes.txt`, и выполните из каталога проекта:

```powershell
node scripts/prepare-apk-release.mjs "путь/ZZWS-7.0.9-production.apk" 7.0.9 "новая-папка-выпуска" "release-notes.txt"
```

Node.js создаст новую папку с APK и `apk-release.json`, рассчитав размер
и контрольную сумму. Скрипт ничего не загружает и не перезаписывает существующие
папки. Последний аргумент можно пропустить для общего описания приложения.
Версию укажите такую же, как в собранном APK; скрипт не проверяет сертификат
подписи и внутренние Android-метаданные.

Загрузите **оба файла в корень GitHub-репозитория в одном коммите**: новый APK
и заменяющий прежний `apk-release.json`. Старые APK можно оставить. Дождитесь
успешной публикации GitHub Pages и заново откройте личный кабинет.
Версия, описание и скачиваемый файл обновятся без изменений кода сайта.

При раздельной загрузке сначала публикуйте APK, затем JSON. Если JSON ссылается
на отсутствующий или неполный файл, кабинет покажет повторную проверку
доступности. Если содержимое APK не совпадает с размером или SHA-256,
скачивание не завершится. Простая замена только APK не обновляет JSON:
для каждого выпуска обязательно публикуйте обновлённые данные выпуска.

Для изменения одного описания достаточно отредактировать поле `description`
в `apk-release.json` на GitHub, сохранив остальные поля. HTML не поддерживается;
переносы строк внутри JSON записываются как `\n`.

APK на GitHub Pages — публичный файл. Разрешение аккаунта управляет кнопкой
и входом в приложение; оно не превращает публичное хранилище в закрытое.
