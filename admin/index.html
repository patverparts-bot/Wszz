Здесь меняются цены и общий доступ для всей группы. Дополнительно учитываются персональные разрешения и исключения каждого клиента. Пока настройки не сохранены, действует прежняя логика.

Хранилище данных

Использование базы и данные пользователей. Отчёт обновляется по запросу.

Размер базы включает индексы и выделенное служебное место. Размеры разделов пользователя — содержимое JSON в UTF-8; они не равны месту на диске. После очистки PostgreSQL может сохранить освобождённые страницы для повторного использования.

Файлы сайта на GitHub, код Edge Functions, WAL и системные журналы сервера в эти показатели не входят.
